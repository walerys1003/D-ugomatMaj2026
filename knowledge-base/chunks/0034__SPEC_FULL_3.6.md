# 3.6 — PDF Generation

_source: SPEC_FULL · tags: misc · line 99 · 296 chars_

Puppeteer (headless Chrome) — renderowanie HTML → PDF. Wybrany zamiast bibliotek jak jsPDF/PDFKit, ponieważ: pixel-perfect rendering (pismo procesowe musi wyglądać profesjonalnie), obsługa polskich znaków i formatowania prawnego, łatwiejszy templating (HTML/CSS zamiast niskopoziomowego PDF API).
