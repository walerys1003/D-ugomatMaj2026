# 5.6 — Responsywność

_source: SPEC_FULL · tags: frontend · line 851 · 426 chars_

Breakpoints: sm 640px, md 768px, lg 1024px, xl 1280px, 2xl 1536px. Mobile (375–768px): single column, bottom navigation bar, full-width buttons, drawer zamiast dropdown, larger touch targets (min 48×48px). Tablet (768–1024px): 2-column layout gdzie możliwe, sidebar collapsible. Desktop (1024+): 3-column layout (sidebar + content + context panel), hover states, keyboard shortcuts.
