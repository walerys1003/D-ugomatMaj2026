# 14.1 — Landing Page — struktura sekcji

_source: SPEC_FULL · tags: frontend, payments, modules, security, brand, strategy · line 2227 · 1799 chars_

Hero Section: nagłówek „Bronisz się przed komornikiem? Pomożemy." + podtytuł „Automatycznie generuj profesjonalne pisma procesowe. Taniej niż prawnik. Szybciej niż myślisz." + 2 CTA buttons: „Skanuj nakaz za darmo" (primary, zielony) + „Zobacz cennik" (secondary, outline). + ilustracja: shield icon z animacją (SVG animated), tło gradient shield-50 → white. + Trust badge: „Ponad [X] wygenerowanych pism | [Y] skuteczność | 14-dniowa gwarancja". Background: subtle grid pattern (opacity 3%), diagonal gradient shield-50 do white.
Jak to działa (4 kroki): karty z ikonami + numerami + opisami. Krok 1: Wgraj dokument (ikona: upload cloud). Krok 2: AI analizuje sprawę (ikona: magnifying glass + brain). Krok 3: Wygeneruj pismo (ikona: document with sparkle). Krok 4: Pobierz i wyślij do sądu (ikona: download + stamp). Animacja: karty pojawiają się sekwencyjnie (staggered fade-in) przy scroll.
Social proof / Testimonials: karousel 3–5 testimoniali. Format: zdjęcie (avatar generyczny), imię + lokalizacja, gwiazdki, cytat. „Dzięki Długomatowi złożyłam sprzeciw w 20 minut. Sąd oddalił nakaz." — Anna, Kraków. Trust badges poniżej: „Dane chronione szyfrowaniem AES-256", „Płatności przez Stripe", „Zgodne z RODO".
Cennik (pricing table): 3 kolumny (Sprzeciw EPU / Pakiet Komornik / Pełna Tarcza), badge „NAJPOPULARNIEJSZY" na środkowej, lista cech z checkmarkami, przekreślona cena prawnika, przycisk CTA.
FAQ: accordion (10–15 pytań). Schema.org(http://schema.org/) FAQPage markup. Pytania: „Czy to legalne?“, „Czy AI może pisać pisma procesowe?”, „Co jeśli mam mało czasu?“, „Czy potrzebuję prawnika?”, „Jak działa gwarancja?“, „Jakie metody płatności akceptujecie?”, etc.
Footer: logo, nawigacja (Produkty, Cennik, Blog, Kontakt, Regulamin, Polityka prywatności), social links, NIP, adres firmy.
